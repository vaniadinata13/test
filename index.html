Modul 1: Prinsip Dasar Sains

Bagaimana Sensor Warna Bekerja Secara Umum?

Sensor warna tidak memiliki "mata manusia". Melainkan, sensor warna mengandalkan interaksi fisika antara sumber cahaya, penyerapan spektrum warna, dan detektor fotodioda.

Tahap 1: Emisi Cahaya

Pancaran Cahaya Putih (LED)

Sensor menembakkan cahaya putih ke permukaan objek. Cahaya putih merupakan gabungan dari seluruh spektrum warna tampak (Merah, Hijau, Biru / RGB).

Spektrum: White = R (650nm) + G (510nm) + B (475nm)
Tahap 2: Refleksi & Absorpsi

Hukum Penyerapan Spektrum

Objek berwarna menyerap panjang gelombang tertentu dan memantulkan sisanya. Contoh: Objek Kuning menyerap biru, lalu memantulkan spektrum merah dan hijau kembali ke sensor.

Objek Merah: Pantulkan R, Serap G & B
Tahap 3: Konversi Fotolistrik

Fotodioda & Microcontroller

Fotodioda dengan filter optik (Red, Green, Blue, Clear) menangkap foton pantulan dan mengubahnya menjadi arus listrik mikro. Nilai analog ini lalu diubah menjadi nilai digital oleh mikrokontroler.

Foton ➔ Arus Mikro ➔ ADC ➔ Nilai Digital

Pemrograman di LEGO® SPIKE App

Sensor ini didukung penuh dalam lingkungan visual Scratch Block (Word Blocks) maupun bahasa teks Python:

when [Port A] color is [ red v ]
wait until < ( [Port A] reflected light intensity ) < [ 30 ] > 
# SPIKE Prime MicroPython
from hub import port
import color_sensor

# 1. Baca Warna (Color Mode)
warna = color_sensor.color(port.A)

# 2. Baca Intensitas Pantulan (Reflected Light)
pantulan = color_sensor.reflection(port.A) # 0 - 100%

# 3. Baca Nilai RGB Mentah (Raw Tuple)
r, g, b, i = color_sensor.rgbi(port.A)

Modul 3: Mode Pengoperasian

Perbedaan Fitur: Color vs Light Intensity

Kekuatan utama sensor LEGO Spike terletak pada fleksibilitas modenya. Memilih mode yang tepat adalah kunci sukses robotika!

Mode 1

Color Detection

Mendeteksi dan mengembalikan nama atau ID diskrit warna spesifik.

  • Status LED: LED putih menyala menerangi objek.
  • Output: Nama warna (e.g. "red", "yellow") atau integer ID (0 - 10).
  • Kasus Penggunaan: Pemilah barang otomatis (Color Sorter), parkir zona warna, pembacaan rambu rute.
color_sensor.color()
Paling Populer
Mode 2

Reflected Light

Mengukur persentase (0% - 100%) jumlah cahaya pantulan dari permukaan.

  • Status LED: LED internal menyala terang menembak ke bawah.
  • Output: Nilai rasio kontinu 0% (sangat gelap/hitam) hingga 100% (sangat putih/terang).
  • Kasus Penggunaan: Line Following (Pengikut Garis), deteksi jurang/tepi meja, kontrol PID.
color_sensor.reflection()
Mode 3

Ambient Light

Mengukur tingkat intensitas cahaya lingkungan sekitar tanpa bantuan lampu sensor.

  • Status LED: LED MATI! Sensor hanya menerima cahaya luar.
  • Output: Nilai 0% (ruangan gelap gulita) hingga 100% (sinar senter/matahari).
  • Kasus Penggunaan: Lampu otomatis malam hari, robot pemburu cahaya (light seeker), alarm anti-pencuri.
color_sensor.ambient_light()
Konsep Emas Kompetisi Robotika

Mengapa Reflected Light Dipakai untuk Line Follower?

Alih-alih mencari warna "Hitam" diskrit yang rawan kesalahan saat robot bergerak kencang, programmer robot menggunakan Intensitas Pantulan (0-100%) dan menelusuri tepi perbatasan (edge) antara warna hitam dan putih.

Rumus Nilai Ambang Batas (Threshold):
Threshold = (Nilai_Putih + Nilai_Hitam) / 2

Contoh: Jika lantai putih terbaca 80% dan garis hitam terbaca 10%, maka ambang batas ideal robot = (80 + 10) / 2 = 45%.
